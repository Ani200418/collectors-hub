# Collectors Hub

Collectors Hub is a modern marketplace and community app for collectors. It helps users discover rare collectibles, save favorite pieces to a personal collection, and browse community posts from other enthusiasts.

## Overview

This app includes:
- a curated marketplace for collectibles such as trading cards, vinyl, comics, toys, coins, and stamps
- category and condition filters with search and sorting
- a personal collection wishlist and saved items tracker
- a community feed for collector highlights and discoveries
- a responsive design with a dark/light theme

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- CSS modules / custom CSS

## Features

### Marketplace
Explore collectible listings with:
- search by item name
- filter by category and condition
- sort by newest, price, or alphabetical order
- infinite scrolling for large result sets

### Community
Browse social posts from collectors and view detailed post pages.

### Collection
Track wishlist and saved items for personal collecting goals.

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local Vite URL shown in the terminal, usually:

```text
http://localhost:5173
```

### Production build

```bash
npm run build
```
